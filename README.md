# FairMod

Stage 0 architecture-only repository for a multi-community GenLayer moderation protocol.

No contract, frontend, deployment configuration, wallet flow, or network state has been created. Read the Stage 0 documents in `docs/` before starting Stage 1.

Target baseline: Studionet (`https://studio.genlayer.com/api`, chain ID `61999`) and `genlayer-js@1.1.8`. This baseline is pinned by product requirement; its exact package API remains a Stage 1 install-and-inspect gate.
